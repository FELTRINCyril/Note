Pied
40 pt, séparateur 1 pt : Réglages · Corbeille — puis nouveau dossier (⌘⇧N) · nouvelle note (⌘N)
Accessibilité
Contraste — libellé sur sélection : blanc sur #007AFF = 4,55:1 (clair) et sur #0A84FF = 4,52:1 (sombre) ✓ AA. Accent jaune → texte noir 88 %. Les rangs secondaires (text.secondary) sont renforcés en mode Increase Contrast (0,50 → 0,72).
Focus ≠ sélection — la sélection est un aplat, le focus clavier un anneau 3 pt : les deux se cumulent sans ambiguïté et le focus reste lisible sur fond d'accent.
Daltonisme — aucune information portée par la seule couleur : chevron pour le pliage, ligne + pastille pour le dépôt, étoile pour les favoris, opacité + curseur pour le drag.
Dynamic Type — toutes les tailles passent par @ScaledMetric ; la ligne utilise minHeight et le libellé peut passer sur 2 lignes en tailles accessibilité.
Reduce Transparency — le matériau .sidebar retombe sur l'aplat #F2F2F5 / #232326. Reduce Motion — pliage et collapse en fondu simple.
VoiceOver — « Produit, dossier déplié, 12 notes », action « Déplier/Replier », lignes atteignables au clavier (Tab / ↑↓ / ←→).
